# OpenMacros+ v2 — contrato (instalação, privacidade, notificações, bandeja, backup)

Complementa [ARCHITECTURE.md](../ARCHITECTURE.md) e [INTEGRATIONS.md](INTEGRATIONS.md). Requisito: Python 3.12+.
Ambiente de desenvolvimento em que este contrato foi escrito (não é requisito): Kali/XFCE X11, Python 3.14,
`org.freedesktop.Notifications` (xfce4-notifyd) e `org.kde.StatusNotifierWatcher` presentes;
`AyatanaAppIndicator3-0.1` + `Gtk-3.0` (GI) instalados; `xclip`, `xsel`, `xdotool`, `pipx` presentes.

## B. Backend (`daemon/`, `hidpp/`, `data/`, `scripts/`, `pyproject.toml`, `tests/` exceto `tests/gui`)

### B1. `type_text` por colagem (corrige acentos/ABNT2)
`{"type": "type_text", "text": "…", "method": "paste" | "keys"}` — `method` padrão **`paste`**.
- `paste`: guarda o CLIPBOARD atual (só texto, timeout 300 ms), coloca o texto no CLIPBOARD
  (`xclip -selection clipboard -i`, fallback `xsel -bi`; Wayland: `wl-copy` se existir), envia
  Ctrl+V via uinput — **Ctrl+Shift+V** se o app em foco for terminal (lista de app_ids de terminal de
  [INTEGRATIONS](INTEGRATIONS.md) §6) — e restaura o CLIPBOARD anterior ~600 ms depois (timer GLib, não bloqueia).
- `keys`: comportamento antigo (layout US).
- Qualquer Unicode; máx. 2000 caracteres (inalterado).

### B2. Privacidade do `ai_prompt`
`{"type": "ai_prompt", "service": "...", "template": "...", "delivery": "clipboard" | "url"}` —
padrão **`clipboard`**.
- `clipboard`: monta o prompt, copia para o CLIPBOARD e abre a página inicial do serviço
  (`https://claude.ai/new`, `https://chatgpt.com/`, `https://www.perplexity.ai/`,
  `https://gemini.google.com/app`) + notificação "Prompt copiado — cole com Ctrl+V".
- `url`: comportamento antigo (prompt no `?q=`), só se o usuário escolher.
- **Detector de segredos** (`daemon/secrets.py`, puro e testado): JWT, `AKIA…`/`ASIA…`,
  `-----BEGIN … PRIVATE KEY-----`, `Bearer …`, `Authorization:`, `password=`/`passwd`/`senha`,
  `api[_-]?key`, hashes (`$2[aby]$`, `$6$`, `$argon2`, NTLM `aad3b435…`, hex ≥ 32), tokens
  base64/alfanuméricos ≥ 32 sem espaços, `ghp_`/`github_pat_`/`xox[bp]-`/`sk-…`. Se detectar, força
  `clipboard` mesmo com `url` e notifica "Seleção parece conter um segredo — não foi para a URL".
- Seleção vazia: notifica "Nada selecionado" e não abre nada.

### B3. Notificações e OSD (`daemon/notify.py`)
Via D-Bus `org.freedesktop.Notifications.Notify` (Gio, assíncrono; se o serviço não existir,
só loga). Usa `replaces_id` por categoria para não empilhar. app_name "OpenMacros+",
ícone `io.github.openmacros.App`.
- Bateria: ao cair para ≤ `battery_threshold` (uma vez por ciclo de descarga; rearma ao carregar
  ou subir 5 pontos acima) e crítica ≤ 5 % (urgência 2).
- OSD de perfil: "Perfil: Firefox" / "Perfil: Todos os aplicativos" ao trocar (timeout 1200 ms).
- OSD de gesto/ação: "Gesto ↑ — Nova aba" ao disparar gesto (timeout 800 ms).
- Conexão: "M720 conectado/desconectado".

Preferências globais em `config.json` → `"preferences"`:
```json
{"notify_battery": true, "battery_threshold": 15, "osd_profile": true,
 "osd_gestures": true, "notify_connection": false, "ai_delivery_default": "clipboard"}
```

### B4. Perfil vazio some sozinho
Se `SetProfileAssignment(..., "null")` ou `SetProfileSetting(..., "null")` deixar o perfil sem
assignments e sem settings, o perfil é removido (e `DeviceUpdated` emitido).

### B5. Backup
- `ExportConfig() → s`: JSON `{"openmacros_export": 1, "exported_at": ISO8601, "devices": {...},
  "smart_actions": {...}, "preferences": {...}}` (sem `baseline` nem estado volátil).
- `ImportConfig(s json, b merge) → b`: valida tudo com os mesmos validadores de entrada
  (limite 512 KiB só para este método); `merge=false` substitui, `true` mescla por chave;
  reaplica nos dispositivos online; erro `InvalidArgument` com mensagem legível.

### B6. D-Bus — membros novos (`io.github.openmacros.Manager1`)
| Membro | Assinatura | |
|---|---|---|
| `GetPreferences()` | `→ s` | objeto JSON acima (com padrões preenchidos) |
| `SetPreference(s key, s value_json)` | `→ b` | valida tipo/faixa (threshold 5..50) |
| `ExportConfig()` | `→ s` | |
| `ImportConfig(s json, b merge)` | `→ b` | autorizado como método de escrita |
| `PreferencesChanged(s prefs_json)` | sinal | |
| `ActionTriggered(s id, q cid, s label)` | sinal | label legível p/ GUI/bandeja |

### B7. Instalação de usuário (sem sudo) — `scripts/install.sh` / `scripts/uninstall.sh`
- Modo padrão "dev": lançadores em `~/.local/bin/{openmacrosd,openmacros,openmacros-tray}` que fazem
  `exec env PYTHONPATH=<repo>/src python3 -m openmacros.<...>` (usa os pacotes do sistema: gi, evdev,
  pyudev, xlib). Opção `--pipx` (`pipx install --system-site-packages`).
- `~/.config/systemd/user/openmacrosd.service` (ExecStart=%h/.local/bin/openmacrosd, mantendo o
  endurecimento de `data/systemd/openmacrosd.service`), `systemctl --user daemon-reload` e
  `enable --now` (com `--no-start` para não iniciar).
- Desktop file `io.github.openmacros.App.desktop` em `~/.local/share/applications`, ícone
  `data/icons/io.github.openmacros.App.svg` em `~/.local/share/icons/hicolor/scalable/apps/`,
  autostart da bandeja `~/.config/autostart/io.github.openmacros.Tray.desktop`.
- Idempotente; imprime ao final (não executa) os comandos sudo da regra udev
  (`70-openmacros.rules`), incluindo a remoção de uma regra local antiga do autor, se existir.
- `pyproject.toml`: novo entry point `openmacros-tray = openmacros.tray.main:main`; incluir `data/icons`.

## F. Frontend (`gui/`, `tray/`, `data/icons/`, `tests/gui/`)

- **F1 Bandeja** `src/openmacros/tray/` — processo separado, **GTK3 + AyatanaAppIndicator3**
  (nunca importa `openmacros.gui`, que é GTK4). Cliente D-Bus próprio e mínimo (Gio). Ícone pela menor
  bateria (`battery-level-N0-symbolic`, `battery-missing-symbolic` sem serviço). Menu: uma linha por
  dispositivo ("M720 — 80 %"), "Perfil ativo: Firefox", submenu Easy-Switch (ChangeHost), "Abrir
  OpenMacros+" (Gio.DesktopAppInfo / `openmacros`), "Sair". Atualiza por `DeviceUpdated`/`DevicesChanged`/
  `ActiveAppChanged`; reconecta quando o serviço volta (NameOwnerChanged).
- **F2 Preferências** — `Adw.PreferencesDialog` no menu do cabeçalho da tela inicial:
  notificações (bateria + limiar, OSD de perfil, OSD de gestos, conexão), IA (entrega padrão),
  Backup (Exportar… / Importar… com `Gtk.FileDialog`, escolha mesclar/substituir, toast de erro).
- **F3 Painel IA**: seletor "Entrega: Área de transferência (recomendado) / Na URL" com aviso
  curto de que a URL fica no histórico do navegador.
- **F4 Digitar texto**: tirar aviso de "só US"; opção avançada "Simular teclas (layout US)".
- **F5 Aba Sobre** redesenhada no estilo das outras abas (foto/arte, nome, modelo, conexão, bateria,
  firmware/IDs disponíveis no Device JSON, "Restaurar padrões" com confirmação).
- **F6 Ícone do app** próprio: `data/icons/io.github.openmacros.App.svg` (sem marca Logitech).
- **F7** Chips de perfil atualizam ao receber `DeviceUpdated` (perfil vazio some — B4).

## Notas do backend (desvios e esclarecimentos de B)

- **`type_text`**: `method` é sempre normalizado (`paste` por padrão) ao validar. `Selection` ganhou `read_clipboard()`
  (só texto; `None` se vazio/não-texto) e `write_clipboard()` espera o processo pai do `xclip/xsel/wl-copy` sair
  (≤ 300 ms) para o Ctrl+V já encontrar o dono da seleção. Colagens em sequência restauram o CLIPBOARD *original*
  (um único restore, 600 ms após a última). Se o CLIPBOARD anterior não era texto, não há o que restaurar e o
  texto colado permanece. O app em foco vem do `FocusWatcher` (`app_id` ∈ `integrations.TERMINAL_APP_IDS`).
- **`ai_prompt`**: `delivery` é opcional e, se ausente, vale a preferência `ai_delivery_default` (padrão `clipboard`).
  `gemini` sempre usa clipboard (não há `?q=`). Notificação "Prompt copiado" só no caminho normal; no caso forçado
  pelo detector aparece apenas "Seleção parece conter um segredo — não foi para a URL". Seleção só com espaços
  conta como vazia. O segredo é detectado na **seleção**, não no template.
- **`daemon/secrets.py`**: `find_secret(text) -> rótulo | None`. `password/senha/secret/api_key` só disparam com
  atribuição (`=` ou `:` + valor; com `:` o valor precisa ter dígito/símbolo, para "senha: criada" não disparar).
  Hex ≥ 32 exige letra e dígito (SHAs de commit de 40 hex SÃO tratados como segredo, de propósito). Tokens ≥ 32
  sem espaço exigem dígito + (maiúsculas e minúsculas, ou alta entropia); URLs/caminhos/slugs são ignorados.
- **Preferências**: guardadas em `config.json → "preferences"` (só o que o usuário alterou; `GetPreferences` preenche os
  padrões). `SetPreference` também é método de escrita (bloqueado para Flatpak). Valores inválidos no arquivo são descartados.
- **Notificações** (`daemon/notify.py`): `Notifier` assíncrono, `replaces_id` por categoria (`battery:<id>`,
  `connection:<id>`, `profile`, `gesture`, `ai`). Bateria: `BatteryAlerts` (uma vez por ciclo; rearma carregando ou
  a `limiar+5`; crítico ≤ 5 % urgência 2 rearma a ≥ 10 %). Aviso é avaliado em add_device, `online` e `updated`.
  OSD de gesto só para up/down/left/right (o "clique" do botão de gestos não gera OSD). OSD de perfil sai uma vez por
  troca de foco que mude o perfil ativo de algum dispositivo.
- **`ActionTriggered(id, cid, label)`**: emitido para press/trigger vindos de botões/gestos (não para `RunAction`);
  rótulo via `daemon/labels.py` (ex.: "Gesto ↑ — Nova aba", "Próxima faixa"); ações `default`/`disabled` não emitem.
  `ActionEvent` ganhou o campo `direction`.
- **B4**: aplicado em `Config` (perfil vazio é removido ao gravar e ignorado ao carregar). Correção junto: o baseline de
  settings agora é restaurado mesmo quando o perfil que sobrepunha a chave deixa de existir, e é descartado após
  restaurar (antes o valor do perfil ficava no dispositivo).
- **Export/Import**: `merge=false` substitui só as **seções presentes** no arquivo (devices/smart_actions/preferences);
  seções ausentes ficam como estão. O `baseline` local é preservado. Settings são validadas sem conhecer o
  dispositivo (faixas largas); valores fora da faixa do hardware geram `Error` ao reaplicar. Ações `command` não
  têm o executável conferido na importação (só ao executar). Referências a Smart Actions inexistentes no arquivo
  são rejeitadas; referências antigas que ficarem órfãs viram `default`. Tudo-ou-nada: falha de validação não altera nada.
  Limites: 512 KiB, 64 dispositivos, 200 perfis/dispositivo, 200 Smart Actions.
- **systemd**: removido `PrivateTmp=yes` (esconde `/tmp/.X11-unix`, que python-xlib e o clipboard usam). Mantidos
  `NoNewPrivileges`; adicionados `LockPersonality`/`RestrictRealtime` (seccomp, sem user namespaces).
- **install.sh**: lançadores usam `/usr/bin/python3` se existir; `PYTHONPATH` do usuário é preservado depois do do repo;
  `Exec=` dos .desktop vira caminho absoluto de `~/.local/bin`. Variáveis de teste: `OPENMACROS_SKIP_SYSTEMCTL=1`,
  `OPENMACROS_UDEV_DIR`. Em instalação com serviço, importa `DISPLAY/XAUTHORITY/WAYLAND_DISPLAY` no systemd --user
  e reinicia o serviço. `uninstall.sh` só remove lançadores que ele mesmo gerou (`--purge` apaga a config).
- `data/io.github.openmacros.desktop` foi renomeado para `io.github.openmacros.App.desktop` (Icon=io.github.openmacros.App) e
  `io.github.openmacros.Tray.desktop` (autostart) foi adicionado.
